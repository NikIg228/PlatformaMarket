# Excel / CSV import runbook

Целевой выбор `replace`, `merge`, `partial`, `price-only` или `stock-only` ещё не
представлен полем режима в текущем `createImportBatchSchema`. Это открытый
контракт R3, а не набор уже доступных переключателей. До его реализации нельзя
обещать замену всего источника или удаление отсутствующих строк.

1. Зафиксировать фактически поддерживаемый путь импорта и ожидаемые изменения полей. Отсутствующая строка не означает удаление; целевой режим не подменять догадкой.
2. Загрузить файл 1000+ строк, проверить preview, заголовки, упаковки, дубликаты и ошибки.
3. Публиковать только строки без блокирующих ошибок; спорные отправить оператору.
4. Повторить тот же неизменённый запрос с прежним idempotency key и проверить отсутствие дублей. Исправленный файл — новый payload/операция с новым ключом; сохранённый ключ не переиспользовать для другого содержимого.
5. Выполнить контрольный заказ и резерв. Зафиксировать checksum файла, job id, результат и время запуска.

На странице импорта доступны XLSX и CSV с одинаковыми 12 колонками и одной
полностью заполненной вымышленной строкой товара. Перед загрузкой замените её
своими данными. XLSX содержит отдельный лист инструкции; данные оформлены
обычной таблицей без цветных заливок и декоративных шрифтов. Штрихкод хранится
как текст, цена — в тенге; партия и срок годности также показаны в примере.
