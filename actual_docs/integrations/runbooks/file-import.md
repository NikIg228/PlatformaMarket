# Excel / CSV import runbook

1. Зафиксировать режим: `replace`, `merge`, `partial`, `price-only` или `stock-only`. Отсутствующая строка не означает удаление без выбранного режима.
2. Загрузить файл 1000+ строк, проверить preview, заголовки, упаковки, дубликаты и ошибки.
3. Публиковать только строки без блокирующих ошибок; спорные отправить оператору.
4. Повторить тот же неизменённый запрос с прежним idempotency key и проверить отсутствие дублей. Исправленный файл — новый payload/операция с новым ключом; сохранённый ключ не переиспользовать для другого содержимого.
5. Выполнить контрольный заказ и резерв. Зафиксировать checksum файла, job id, результат и время запуска.
