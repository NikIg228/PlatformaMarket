# Описания 50 тестовых товаров и стандарт характеристик

Подготовлено 29.09.2026 по текущему публичному каталогу. Редакторские краткие описания основаны на страницах производителей, ссылки приведены у каждой позиции. Краткие описания подключены к блоку «Характеристики» через локальный справочник по точному ID и названию товара; в БД не импортированы. Стандарт ниже — предложение, расширенная таблица параметров ещё не реализована.

## Предлагаемый стандарт блока

Название: «О товаре и характеристики». Внутри: краткое описание (2–3 предложения), таблица параметров, комплектация конкретного предложения, документы производителя.

| Группа | Содержание |
|---|---|
| Идентификация | Бренд, производитель, линейка, точная модель/REF |
| Назначение | Тип товара и область применения; без рекламных обещаний |
| Материалы | Состав/класс материала, консистенция, способ отверждения, оттенок и шкала, масса/объём |
| Ортодонтия | Поколение, High/Low, Short/Long, Narrow, размер, материал |
| Оборудование | Рабочие режимы, питание, диапазоны мощности/скорости, размеры, масса, совместимость |
| Комплект | Упаковка, число единиц, принадлежности; различия комплектов — на уровне предложения |
| Документы | Инструкция производителя, технический лист, источник, дата проверки |

Первые 6–8 полезных параметров видны сразу, остальные раскрываются кнопкой «Все характеристики». Неприменимые поля не показывать. Неизвестные параметры не угадывать. Регистрационные документы РК не подменять CE или документами другой юрисдикции. Срок годности и гарантия конкретной поставки относятся к предложению поставщика.

Числовые режимы применения и совместимость переносить только из инструкции для точного REF. Описание семейства не доказывает комплектацию конкретного SKU. Сейчас многие позиции имеют лишь название семейства: для точного наполнения нужны артикулы.

Обнаружено: TETRIC N-BOND UNIVERSAL назван в каталоге «пломбировочным материалом», хотя производитель определяет его как адгезив. Варианты LM с безымянными суффиксами «2»/«3» не следует автоматически считать поколением Activator 2/3. Latelux с суффиксом СТОМИР требует сверки поставщицкого REF с продукцией Latus. Ничего из этого автоматически не переименовано.
