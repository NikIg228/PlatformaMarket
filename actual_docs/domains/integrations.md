# Импорт, ERP и источники данных

Обновлено: 08.10.2026. Исполнение R2/R3
[roadmap](../MAIN_ROADMAP_TO_PRODUCTION_2026-10-06.md).

## Каналы и цель

Поставщик загружает Excel/CSV, работает вручную или подключает учётную систему.
Клиника и поставщик должны самостоятельно подключать доступный своей роли сервис
в кабинете. Заявка в поддержку не является штатным шагом подключения.

Уточнение владельца08.10: основной фокус ERP — **поставщики**. Первый полезный
сценарий клиники оставлен **К ОБСУЖДЕНИЮ С ПАРТНЁРАМИ**. Это не отменяет ранее
принятого самостоятельного подключения обеих ролей: изменение состава запуска
для клиники отдельно не утверждено. Не придумывать обмен клиники до этого решения.

## Тестовые участники и контуры — обсуждение08.10

| Вопрос | Текущий ответ |
| --- | --- |
| Конкретные конфигурации/версии1С участников | ОТКРЫТ: сведения не предоставлены; поддержку любой1С не обещать |
| Реальные клиники/поставщики с МойСклад, готовые к проверке | НЕИЗВЕСТНО: владелец пока затрудняется ответить |
| Отдельная подписка МойСклад с тестовыми данными | ПРЕДЛОЖЕНО владельцем как возможный контур обкатки; тариф, аккаунт и приобретение ещё не определены |

В случае выбора такого контура использовать выделенную тестовую организацию
и synthetic данные. Это позволяет проверять фактический API выбранного сервиса,
но не заменяет приёмку процесса у реального поставщика/клиники и не даёт
автоматический LIVE_VERIFIED. Условия API выбранного тарифа проверяются до
подключения; текущая запись не утверждает тариф или возможности подписки.
Отдельно определить владельца тестового аккаунта и ожидаемый сценарий проверки.

| Канал | Текущая основа и граница |
| --- | --- |
| Excel/CSV | Parser, mapping, validation, matching и preview; неоднозначность требует решения |
| AI-стандартизатор | Требуется владельцем, R3.7; существующее rule-based matching не является AI |
| МойСклад | Адаптер есть; конкретный tenant, направления и live cycle не приняты |
| 1С | Серверный протокол агента есть; конфигурация/версия, installer и реальная база требуют выбора/приёмки |
| Custom API | Адаптер есть; tenant mapping и внешний контракт проверяются отдельно |

## Процесс и данные

Целевой мастер: выбор поддерживаемой конфигурации → авторизация/привязка агента →
health → настройки направлений/складов/прайса → preview → первая синхронизация →
ошибки/retry/reconcile/отключение. Первая полезная операция клиники ещё выбирается.
Текущий SettingsSources отправляет SupportTicket; это известный разрыв UI.

AI применяется только к стандартизации Excel/CSV под правила маркета.
Raw rows сохраняются, неоднозначность подтверждается; цена/остаток не выдумываются,
валидация и import rollback остаются обязательными. AI-помощники вне текущего плана.

Источник цены и остатка выбирается по полю, а не по последнему сообщению.
ERP availability ограничивается лимитом предложения, не увеличивается им.
Нужны UOM/version/freshness и корректное отражение локального/внешнего резерва без
двойного вычитания; manual overrides не считаются автоматически совместимыми.
