## Как поддерживать справочники

Новый принятый результат и его критерии записываются в существующий пункт roadmap;
нерешённый бизнес-вопрос — только в OPEN_QUESTIONS. Здесь изменяется техническая
детализация: схема/API/состояния/consumers и ссылка на evidence. Не дублировать
чекбоксы или отдельную актуальную анкету. Принятое решение, проект схемы, наличие
кода, scoped PASS и внешний receipt — разные состояния.

Нужный интерфейс входит в DoD доменной вертикали. Исторические инструкции запуска
не заменяют риск-матрицу Workflow и не разрешают рабочие данные или live вызовы.
При расхождении с roadmap не выбирать удобную версию: установить позднее решение
или сохранить конкретный конфликт в OPEN_QUESTIONS.
