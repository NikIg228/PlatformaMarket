## План и проверки

- Поведение: агент начинает с актуального описания и выбранного пункта roadmap;
  требования, реализация и evidence различаются; архив не запускает работу.
- Риски: потеря бизнес-правил, открытых обязательств и evidence; сломанные ссылки;
  вмешательство в чужой WIP; случайная публикация staged-продуктовых изменений.
- Изменения: два основных документа, навигация и правила; датированный архив
  заменённых материалов с совместимыми старыми адресами. ADR, контракты,
  эксплуатационные runbooks и незавершённые карточки остаются справочниками.
- Gates: локальные ссылки/anchors изменённых документов, карта переноса остатка,
  сохранность архивного текста и исходного WIP/index, команды по package scripts,
  review собственного diff и git diff --check. Runtime suites не применимы.
- Публикация: только собственный diff, без чужого staged/WIP; если отделение
  невозможно без зависимости от чужих правок — явно PUBLICATION_BLOCKED.
