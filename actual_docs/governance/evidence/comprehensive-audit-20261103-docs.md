## Проверки и ограничения

Локальные проверки выполнялись без зависимостей, app build, БД и браузерных
suite, поскольку это документационная часть общего аудита:

- `node .tmp/comprehensive-audit-20261103/docs-inventory.mjs`: полный набор
  Markdown/MDX, разрешение локальных Markdown file links и anchors.
- `node .tmp/comprehensive-audit-20261103/docs-manifest.mjs`: SHA256 и сравнение
  relocated bodies с исходниками из зафиксированного Git revision.
- `git diff --check`: отсутствие whitespace errors; предупреждения CRLF/LF
  не являются failure этой проверки.

В проверенном срезе: ноль неразрешённых локальных file links и ноль
неразрешённых anchors. Внешние URL не проверялись сетью. Проверка ссылок
Markdown не означает проверку всех путей в code fences, HTML или generated
OpenAPI. Пять root npm-script кандидатов разобраны вручную: `start` относится
к workspace web и существует; `alias` является словом в prose; `dev:` и
`verify:ui-contract:4` являются командой с последующим двоеточием и текстом
результата. Подтверждённых отсутствующих команд среди них нет.

Проверка Python не запускалась: интерпретатор отсутствует; инвентаризация
выполнена штатным Node. Это ограничение инструмента, не дефект приложения.
SHA в CSV фиксирует момент документационной сверки; audit reports и checkpoint
обновляются координатором параллельно. Итог всего поручения и ограничения
runtime/security/live environment определяет [общий отчёт](comprehensive-audit-20261103.md).
Не выбранные внешние providers, реализация import modes, V16/V17 и прочие
открытые решения не закрываются редакцией документов.
