# Требования: результат полного документационного чтения 04.11

Принятое требование, предложение, незакрытая подготовка и реализация — разные
состояния. Этот инвентарь не меняет решения владельца и не присваивает runtime PASS.
База: `af7149699aac16c0127df6852b231fb66f00b08b`.

[JSON](requirements-inventory.json) сохраняет точный источник, строку, SHA256,
исходную формулировку и раздельные статусы; [CSV](requirements-inventory.csv) — краткий
индекс. Всего 502 исходных записи: 187 правил текущего свода, 51 вопрос V,
42 сценария AT, 29 вхождений decision gates, 181 строка трассировки Q/Т/П и
12 сгруппированных уточнений DG из последнего журнала. Повторные упоминания
одного DG — разные source records, не новые требования. Это не 502 независимые функции.
В JSON каждой V-записи сохранён весь относящийся раздел с вариантами: рекомендация
и невыбранный вариант остаются PROPOSED, даже если выделены жирным.

Основные источники: текущие `BUSINESS_RULES_AND_IMPLEMENTATION.md`,
`UNIFIED_SPEC_MARKET_REQUIREMENTS_2026-10-29.md`,
`governance/MARKET-IMPLEMENTATION-QUESTIONNAIRE.md` и
`governance/ROADMAP-QUESTIONS-AND-DECISIONS.md`. Все прочитаны полностью;
индекс извлечён из текущих файлов, а не скопирован из прежнего CSV187.
