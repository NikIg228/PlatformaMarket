## Какая польза доказана

В Settings из 11 прежних необязательных запросов при входе в каждый раздел теперь
активны 0–4, в зависимости от раздела; denied permission/нет Business — 0.
Tasks после hover-prefetch: раньше 1 запрос hover + 1 повтор при входе, теперь 1 + 0.
Dashboard переносит запрос на hover (0+1 → 1+0), а не устраняет необходимый запрос.
Leads hover: 3 → 2; неизвестный /app: 3 → 0. Это счётчики выбранных запросов,
не измерение HTTP latency, полного трафика, LCP или пользовательской скорости.

Снижена связность крупных файлов: router 1045→80 строк, Settings model 630→307,
Pricing 649→218, integrations 958→338. Код перенесён в осмысленные модули;
общее число строк не считается метрикой ускорения. Inbox остаётся крупным (1658 строк),
то есть задача не превратила весь frontend в идеальную архитектуру.
Конкретная пользовательская польза — отсутствие устаревших деталей интеграции,
защита выбора при записи, корректный logout и меньше лишних запросов.
