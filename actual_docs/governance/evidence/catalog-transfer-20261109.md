не приёмка коммерческих платежей, оформления заказов или юридических документов.

товары с ценами/остатками, не затрагивая CRM. Отдельно разрешены подтверждение

## Границы и история попыток

У 450 исходных карточек нет собственных предложений. Ещё у одной карточки оба
предложения приостановлены, поэтому публично видны54, хотя все505 перенесены.
Новые цены/предложения для этих карточек не выдумывались.

Пять старых PDF тестовых договоров в локальном файловом хранилище не совпадают
с checksum их записей. Эти файлы не копировались и не выдаются за подтверждённые
оригиналы. Перенос каталога не исправляет историческую полноту этих документов.

До запуска ВМ: SSH2timeout/HTTPS1timeout; после сообщения владельца о запуске
соединение восстановилось. Docker cp в read-only rootfs не выполнился; пакет
затем передан штатно в существующий writable `/tmp` tmpfs, защиты не менялись.
Первый apply откатился целиком из-за не-UUID actorId в служебной записи аудита.
После использования null для системного actor и включения аудита в dry-run
повторный dry-run и apply PASS. Первый compose-вызов не выполнил restart из-за
CR в последнем аргументе Windows pipe; после нормализации входа API/worker PASS.
Playwright CLI отсутствовал; использована уже установленная библиотека проекта
без установки зависимостей. Исходные FAIL не считаются успешными проверками.

App build/полный E2E локально не повторялись: задача меняла данные/конфигурацию,
а не приложение. Проверены backup/rollback, точность данных, целевой HTTP/browser
путь и сохранность CRM. Эта запись не заявляет результат нового GitHub CI.
